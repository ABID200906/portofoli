Inovasi Smart Aquaponik

Ubah Lahan Terbengkalai Jadi
Sentra Pangan Cerdas

Solusi inovatif untuk mengatasi lahan terbengkalai bekas industri di Kabupaten Tangerang[cite: 3, 12, 15]. Sistem ini mengintegrasikan akuakultur dan hidroponik berbasis teknologi Internet of Things (IoT) untuk mendukung ketahanan pangan lokal dan program Makan Bergizi Gratis (MBG) secara berkelanjutan[cite: 16, 22, 24].

Sensor Multi-Parameter Terpadu

Dilengkapi pembacaan setiap 1 detik oleh sensor pH, TDS untuk kualitas nutrisi, sensor suhu dan kelembapan udara DHT22, serta sensor suhu air DS18B20 untuk memantau ekosistem secara lengkap[cite: 55, 56, 57, 58, 73, 103].

Kendali ESP32 & Cloud IoT

Menggunakan otak mikrokontroler ESP32 WROOM-32 yang terhubung ke Firebase Realtime Database[cite: 53, 68]. Data dikirimkan dan divisualisasikan langsung melalui Web Dashboard Aqupon.id[cite: 69].

Sistem Otomatisasi Pintar

Terdapat pemberi pakan ikan otomatis berservo, penyesuaian daya pompa air jika suhu tinggi, serta aktivasi lampu UV secara mandiri jika kualitas air (TDS) memburuk[cite: 77, 78, 83, 106].
